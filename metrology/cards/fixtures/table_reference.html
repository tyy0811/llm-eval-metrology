Illustrative fixture. Not a result. Every pair name and every figure in the table below is invented to exercise the layout, and the digits are patterned so that no cell can be read as a measurement: the two count columns are four-digit repeated digits, and the two p-value columns are repeated digits or an exact 1.000. No experiment produced them. Fixtures are the one sanctioned home for illustrative numbers (PLAN.md section 2). This page is a review target rather than renderer output: no renderer for this table exists yet, and none is written until this file is approved (D1.3).

Pair table reference

The pair table. In the finished document it is a sibling of the cards, not part of one, and it lands between the family card above and the pair cards below. It takes the card's surface on purpose, so that it reads as a member of the set: left bare it would be the only block on the page sitting directly on the page ground, which reads as a gap between two card groups. On a narrow screen the table scrolls inside its own block, and the page never scrolls sideways. That scroll container is also a labelled region and a tab stop, so a reader on a keyboard can scroll it on engines that do not focus scrollers by themselves; the renderer emits those three attributes. Four invented rows stand in for the nineteen the document will carry. The five column headers are the strings in metrology.reporting.FINDINGS_COLUMNS, verbatim and in order, because the renderer is handed that same tuple. There is deliberately no per-pair floor column (D3.6): those values live in neither corpus file, and deriving them here would recompute inside a layer that promises not to. The gateway floor is stated once in the finished document, on the family card. Labels in teal name the structural element and are annotations for review only; the renderer does not emit them, exactly as in verdict_reference.html.
